## Global Constraints
- PostgreSQL 17 (`citext`, `GIN (custom_fields jsonb_path_ops)`, UUIDv7 PKs via `HasUuidV7`).
- Strict `Controller -> FormRequest/Data DTO -> Action -> Model` + Laravel `Policies`.
- Strict Siloed Scoping (`HasSiloVisibility::scopeVisibleTo`) across all REST/Inertia queries, timeline fan-out, and Reverb ID-only broadcasts.
- Optimistic locking (`version`) on Deals (`409 Conflict`) and unified `MoveDealStageAction` stage-gate validation (`422 Unprocessable Entity`).
